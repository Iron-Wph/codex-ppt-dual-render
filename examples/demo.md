# 一份结构，两个出口

> Codex 驱动的 PPT 自动化 MVP

## 核心方法

- 先确定主张和阅读顺序，再写页面。
- 用 `deck.spec.json` 同时驱动 HTML 与原生 PPTX。
- 用截图、结构检查和人工复核把结果拉回可交付状态。

## 双输出

- HTML：适合浏览器演示、动效和快速迭代。
- PPTX：标题、正文、形状和流程节点保持可编辑。
- 共享规格：页面语义、层级、分组和连接关系只维护一份。

## QA 闭环

- Schema：规格是否完整、合法、可追踪。
- Geometry：是否溢出、重叠、裁切或出现空白页。
- Cross-output：HTML 与 PPTX 的页数、标题和核心内容是否一致。
- Review：根据问题定位元素，修订后重新渲染。
